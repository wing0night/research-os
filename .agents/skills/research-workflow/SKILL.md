# Research Workflow

把一个模糊研究想法变成最小可验证实验。

## 工作方式

1. 先读相关代码、配置、数据说明、已有日志和论文，不要马上改代码。
2. 写清楚：问题、假设、输入、输出、评价指标和不做什么。
3. 设计最小实验：只改变一个关键变量，保留 baseline。
4. 实现时同时补配置、运行命令和必要测试。
5. 运行验证并记录命令、commit、结果路径和失败边界。
6. 最后输出：结论、证据、未验证项、风险和下一步。

## VLA 检查清单

- 观察、语言、动作的时间对齐
- 坐标系、动作单位、频率和归一化
- 数据划分与轨迹泄漏
- 仿真到真实的差异
- 动作限幅、碰撞检查和急停
- success rate 与失败类型，而不只是 loss

## 音乐检查清单

- 音频、MIDI、歌词、caption 的对齐
- 训练/测试泄漏与重复片段
- 长度、响度、采样率和切片策略
- 理解任务与生成任务的独立评测
- 音乐结构、节奏、音色、情绪和文本一致性
- 主观评测的协议、样本量和随机性

## 输出格式

```text
问题：
假设：
最小实验：
改动文件：
运行命令：
结果与证据：
结论：
未验证 / 风险：
下一步：
```
