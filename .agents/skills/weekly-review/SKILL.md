# Weekly Review

帮助用户完成一页纸周复盘，保持事实、结论和计划分开。

## 步骤

1. 阅读本周记录、commit、实验日志和未完成事项。
2. 合并重复内容，区分“完成 / 进行中 / 未验证 / 阻塞”。
3. 提炼最多 3 条真正有证据的结论。
4. 找出一个效率问题和一个可复用方法。
5. 生成下周最多 3 个任务，每个任务都写完成标准。

## 输出

```text
本周一句话：
完成：
关键结论：
本周感悟：
时间浪费：
下周 3 件事：
阻塞与决策：
需要补的证据：
```

不要把“做过”写成“做成”，也不要替用户补写没有提供的结果。
