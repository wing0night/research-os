# Research Delivery

任何重要任务都留下一个能被未来的自己接手的工件。

## 最小字段

- Objective：要解决什么
- Scope：做什么 / 不做什么
- Inputs：代码、数据、论文、日志
- Output：要交付什么
- Acceptance：什么算通过
- Evidence：命令、commit、图表、日志或链接
- Status：Backlog / In Progress / In Review / Verified / Done / Blocked
- Risk：没验证什么、为什么、影响是什么
- Next step：下一步动作

## 完成门

没有验收标准和证据，不写 Done；没有运行的测试写 Not run；未知内容写 Not verified。

## 结束汇报

```text
Task:
Result:
Verification:
Uncovered / Not run:
Risk / Blockers:
Next step:
```
