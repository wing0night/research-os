# 日记 / Diary

这里是个人信息的第一落点。日记不需要一开始就分类正确：先记录，再在你说“总结”时按 `daily-journal` skill 处理和归档。

## 目录

```text
entries/YYYY/              原始日记，按日期保存，永不覆盖
summaries/YYYY/            周期性总结和归档
_template.md               每日日记模板
```

## 你可以直接这样说

```text
记日记：今天……
补充个人信息：我发现……
把下面这段记到昨天的日记：……
总结本周日记。
总结 2026-09-01 到 2026-09-21 的日记并归档。
```

默认行为：记录时保留原始表达；总结时提炼事实、感受、模式、项目行动和长期记忆候选；不删除历史，不把未经确认的推测写进深层记忆。
