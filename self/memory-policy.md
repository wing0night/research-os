# 记忆分层规则

## 四层

| 层 | 位置 | 保存什么 | 典型生命周期 |
|---|---|---|---|
| 深层自我 | `self/` | 稳定特性、价值、长期主线、边界 | 月 / 年 |
| 当前状态 | `now/` | 阶段目标、注意力预算、进行中事项 | 周 / 月 |
| 情景与证据 | `weekly/`、`evidence/`、`projects/` | 某次实验、练习、决定、结果 | 日 / 周 / 项目 |
| 瞬时入口 | `inbox/` | 突然想法、临时任务、未分类材料 | 数小时 / 数天 |

## 归档决策

1. 先记录原话和日期。
2. 判断它是事实、推测、决定还是待办。
3. 若只与一个项目相关，留在项目或证据中。
4. 若跨多个项目且长期稳定，再提炼到 `self/`。
5. 任何未验证内容都显式标为“未验证”，不要因为写进深层目录就把它变成事实。
